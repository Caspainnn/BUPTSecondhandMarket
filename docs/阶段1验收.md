# 阶段 1 验收单：最小物品交易闭环

> 目标环境：`cloud1-d1gi2dzcp1275d460`  
> 验收规则：所有项目初始均为 `待验收`；只有用户亲自验证并明确确认后，才能改为 `已完成`。本地测试通过不等于云端部署或真机验收通过。

## 部署前置清单

1. 在微信开发者工具中上传并部署 `setupStage1Database`，选择“云端安装依赖”。
2. 云端测试参数使用 `{ "confirm": "INIT_STAGE_1" }`，确认返回六个集合及索引、权限声明。
3. 按 `database/README.md` 创建所有普通/唯一索引，并将六个集合的客户端读写权限均设为 `false`。
4. 依次上传并部署 `postApi`、`conversationApi`、`messageApi`、`transactionApi`，全部选择“云端安装依赖”。
5. 从云端删除一次性函数 `setupStage1Database`；不要删除本地源码。
6. 清缓存并重新编译，再使用两个不同微信账号执行下表。
